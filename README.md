# Практика ML: линейные модели, градиентный спуск и нейронные сети

Учебно-практический проект по машинному обучению. В одном Jupyter Notebook собраны эксперименты от аналитического решения линейной регрессии до нейронных сетей на PyTorch.

Проект показывает не только умение использовать готовые модели из `scikit-learn`, но и понимание математики: как работает градиентный спуск, зачем нужна регуляризация, как оценивать качество моделей и сравнивать разные подходы.

---

## Что реализовано

### 1. Линейная регрессия на датасете Diamonds

- Аналитическое решение через нормальное уравнение.
- Сравнение с `LinearRegression` из `scikit-learn`.
- Расчёт MAE и MSE.
- Визуализация зависимости цены от каратности.
- Реализация собственного градиентного спуска.
- Исследование влияния `learning rate`:
  - `0.0000001`
  - `0.001`
  - `1`
- Сравнение с `SGDRegressor`.
- Модель только по признаку `carat`.
- Регуляризация `Ridge` и `Lasso`.

### 2. Логистическая регрессия

- Классификация на синтетических данных `make_blobs`.
- Визуализация разделяющей прямой.
- Логистическая регрессия на FashionMNIST.
- Матрица ошибок и `classification_report`.

### 3. Нейронные сети на PyTorch

- Простая полносвязная сеть `784 -> 10`.
- Более гибкая сеть `784 -> 128 -> 128 -> 10`.
- Эксперименты с:
  - количеством эпох;
  - `learning rate`;
  - оптимизаторами `SGD` и `Adam`.

## Ключевые результаты

### Diamonds

| Модель | MAE | MSE |
|---|---:|---:|
| Аналитическое решение | 1007.46 | — |
| `SGDRegressor` | 730.05 | 1 245 906.76 |
| Только по `carat` | 1003.89 | 2 347 993.29 |
| `Ridge` | 729.71 | 1 225 576.56 |
| `Lasso` | 729.71 | 1 225 574.60 |

Вывод: даже простая линейная модель по всем признакам работает заметно лучше, чем модель только по каратности. Регуляризация даёт небольшое, но стабильное улучшение.

### FashionMNIST

| Модель | Test accuracy |
|---|---:|
| Logistic Regression | 0.8431 |
| SimpleNN `784 -> 10` | 0.8294 |
| FlexibleNN `784 -> 128 -> 128 -> 10` | 0.8120 |
| FlexibleNN + `lr=0.08`, 10 эпох | **0.8641** |
| FlexibleNN + Adam, `lr=0.01`, 5 эпох | 0.8512 |

Вывод: увеличение числа эпох и подбор `learning rate` дали лучший прирост качества. Adam показал хороший результат без тонкой настройки, но уступил более аккуратно настроенному SGD. SimpleNN обучался всего 5 эпох с SGD(lr=0.1), тогда как Logistic Regression сошлась до оптимума — отсюда разница.
